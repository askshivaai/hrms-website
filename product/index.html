Admin, portal and operator shells

Different people, one shared record.

Administrators work in the admin area. Employees use the portal for leave, payslips, goals and notices. Company administration and comparison workflows exist for operators managing more than one company.

Current boundary. Employee portal screens and workflows exist. The current evaluation uses demo personas, so production authentication is a separate requirement. Flutter mobile source exists, but native-device execution was not verified.
